# LibrusWatch ⌚📱

Клиент электронного дневника **Librus Synergia** для **Apple Watch Series 4** (watchOS 10+) и **iPhone** (iOS 16+) с собственным кэширующим бэкендом на **Ubuntu** (Docker + Caddy) и автоматической сборкой `.ipa` через **GitHub Actions**.

![Librus Style UI](https://raw.githubusercontent.com/Alowyyy1/LibrusWatch/main/.github/preview.png)

---

## Возможности

- **Интерфейс в стиле оригинального приложения Librus**:
  - Тёмный дизайн (`#0E1015`) с цветными карточками предметов.
  - Временная шкала с отметками (`08:00`, `08:30`, `09:00`...).
  - Красная линия-индикатор текущего времени дня.
- **Поддержка расписания на всю неделю**:
  - Быстрое переключение дней (`Pon`, `Wt`, `Śr`, `Czw`, `Pt`) сверху.
  - Горизонтальный свайп между днями.
  - Плавная прокрутка колёсиком Digital Crown.
- **Полная поддержка замен (Zastępstwa)**:
  - Белый вертикальный акцент на карточке (в точности как в оригинале).
  - Отображение изменения предмета (`Język polski → Administrowanie systemami operacyjnymi`).
  - Отображение изменений кабинета (`s. 12 → s. 204`) и статуса отмены урока.
  - Тап по карточке открывает экран с полными деталями (заменяющий учитель, причина от администрации).
- **Синхронизация**:
  - Кнопка **Sync** в самом низу списка с тактильным откликом (Haptic feedback) и индикацией времени последнего обновления.
  - Локальное кэширование на часах: расписание открывается мгновенно даже без интернета или iPhone поблизости.
- **Виджет для циферблата (Complication)**:
  - Поддержка `WidgetKit` для циферблатов (Modular, Inline, Circular, Corner): текущий или следующий урок и номер кабинета.

## 1. Развёртывание бэкенда на Ubuntu-сервере

### Требования
- Ubuntu Server с установленным `docker` и `docker compose`.
- Доменное имя (например, `librus.yourdomain.com`), направленное A-записью на IP вашего сервера.

### Быстрый запуск
1. Склонируйте репозиторий на сервер:
   ```bash
   git clone https://github.com/Alowyyy1/LibrusWatch.git /opt/librus-watch
   cd /opt/librus-watch
   ```

2. Настройте конфигурацию:
   ```bash
   cp .env.example .env
   nano .env
   ```
   Укажите ваш домен и сгенерируйте секретные ключи:
   ```env
   DOMAIN=librus.yourdomain.com
   ENCRYPTION_KEY=my-super-secret-encryption-key-32b
   JWT_SECRET=my-jwt-secret-key
   ```

3. Запустите контейнеры:
   ```bash
   docker compose up -d --build
   ```
   Caddy автоматически получит бесплатный SSL-сертификат от Let's Encrypt.
   Проверьте статус: `https://librus.yourdomain.com/health` (должно вернуть `{"status":"healthy"}`).

## 2. Сборка приложения (.ipa) через GitHub Actions

Так как разработка ведётся на Windows, компиляция проекта для iOS и watchOS автоматизирована через облачные виртуальные машины macOS в GitHub Actions.

1. Зайдите в ваш репозиторий: [github.com/Alowyyy1/LibrusWatch](https://github.com/Alowyyy1/LibrusWatch).
2. Перейдите во вкладку **Actions**.
3. Выберите рабочий процесс **Build LibrusWatch IPA**.
4. Нажмите **Run workflow** (или сделайте `git push`).
5. После завершения (~3-4 минуты) скачайте готовый артефакт **LibrusWatch-IPA** (файл `LibrusWatch.ipa`).

## 3. Установка на iPhone и Apple Watch

Файл `LibrusWatch.ipa` содержит внутри себя и приложение для iPhone, и бандл для Apple Watch.

### Установка через SideStore / AltStore:
1. Откройте приложение **SideStore** или **AltStore** на вашем iPhone.
2. Нажмите `+` (добавить приложение) и выберите скачанный файл `LibrusWatch.ipa`.
3. SideStore подпишет приложение вашим Apple ID и установит его на iPhone.
4. Откройте стандартное приложение **Watch** на iPhone, прокрутите вниз до раздела «Доступные приложения» и нажмите **Установить** напротив Librus (если не установилось автоматически).

## 4. Первый запуск и использование

1. **На iPhone**:
   - Откройте приложение **Librus**.
   - Перейдите во вкладку **Ustawienia**.
   - Введите адрес вашего сервера (например `https://librus.yourdomain.com`).
   - Введите логин Synergia (например `1234567u`) и пароль.
   - Нажмите **Zaloguj i połącz z Apple Watch**.
   - Настройки и авторизационный токен автоматически отправятся на ваши Apple Watch.

2. **На Apple Watch**:
   - Откройте приложение **Librus** на часах.
   - Расписание на неделю загрузится на часы.
   - Листайте дни недели горизонтальным свайпом или нажимайте на дни (`Pon`, `Wt`, `Śr`, `Czw`, `Pt`).
   - Для принудительного обновления промотайте в самый низ и нажмите **Sync**.
   - Для добавления виджета на циферблат зажмите экран часов, нажмите «Изменить», выберите ячейку расширения и найдите **Librus**.
